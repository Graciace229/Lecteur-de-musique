## 📋 À propos du projet

Petit lecteur de musique desktop simple et fonctionnel développé en Python.  
Ce projet permet de lire des fichiers audio locaux avec une interface basique.

## ✨ Fonctionnalités

- Lecture / Pause
- Suivant / Précédent
- Gestion de playlist
- Interface graphique (Tkinter ou customtkinter)
- Support des formats courants (MP3, WAV, etc.)

## 🛠️ Technologies utilisées

- **Python** 3.12
- **Bibliothèques** : 
  - `pygame` ou `tkinter` (pour l’interface)
  - `mutagen` (gestion des métadonnées)
  - `customtkinter` (interface moderne)

## 🚀 Installation

1. Clone le repository :
   ```bash
   git clone https://github.com/Graciace229/Lecteur-de-musique.git
   cd Lecteur-de-musique
   ```

2. Crée un environnement virtuel (recommandé) :
   ```bash
   python -m venv .venv
   .venv\Scripts\activate     # Sur Windows
   ```

3. Installe les dépendances :
   ```bash
   pip install -r requirements.txt
   ```
   *(Crée un fichier `requirements.txt` si tu n’en as pas encore)*

4. Lance l’application :
   ```bash
   python music_player.py
   ```
